\# Study Focus Timer ⏱️



A beginner-friendly Python command-line application that helps you stay focused using timed study sessions and short breaks.



\## Features



\- Start customizable focus sessions

\- Start customizable short breaks

\- Live countdown timer

\- Pause and resume the timer

\- Stop a timer early

\- Track completed focus sessions

\- Save study statistics locally in JSON

\- View total accumulated focus time



\## Requirements



\- Python 3.10 or newer recommended

\- Windows terminal or PowerShell



No external Python packages are required.



\## Getting Started



Clone the repository:



```bash

git clone https://github.com/Tejas190p/StudyFocusTimer.git

cd StudyFocusTimer

```



Run the application:



```bash

python main.py

```



\## Menu



1\. Start focus session

2\. Start short break

3\. View statistics

4\. Exit



Use `P` to pause or resume a timer and `S` to stop it early.



\## Data Storage



The application creates `study\_stats.json` to store completed focus sessions and total focus minutes.



\## Technologies



\- Python

\- JSON

\- Command-line interface



\## Learning Goals



This project demonstrates functions, loops, conditional statements, exception handling, countdown timers, keyboard input, file handling, and JSON data storage.
